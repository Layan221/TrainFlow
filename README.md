# TrainFlow

نسخة المصدر المعتمدة لمنصة متابعة التدريب، بواجهات المشرف والمتدرب ودعم المظهر الفاتح والداكن والجوال.

## الترتيب الصحيح للتجهيز

1. ارفع محتويات هذا المجلد إلى مستودع GitHub. لا يلزم إنشاء Supabase قبل رفع الكود.
2. أنشئ مشروع Supabase جديدًا، ثم نفّذ `supabase/schema.sql` من SQL Editor.
3. اتبع `supabase/README.md` لإعداد تسجيل الدخول والبريد ونشر دالة `manage-accounts` وإضافة أسرارها.
4. ضع رابط المشروع والمفتاح العام فقط في `supabase-config.js`، ثم ارفع التعديل إلى GitHub.
5. شغّل `node scripts/build.cjs` وأنشر محتويات `dist` فقط على الاستضافة. إذا كانت الاستضافة متصلة بـGitHub، اجعل أمر البناء `node scripts/build.cjs` ومجلد النشر `dist`.
6. اضبط عنوان الموقع النهائي وروابط إعادة التوجيه في Supabase، ثم اختبر التسجيل والدخول واستعادة كلمة المرور من البريد.

رفع الملفات إلى GitHub يحفظ الكود؛ تشغيل الموقع للعامة يحتاج إعداد الاستضافة أيضًا. يجب اكتمال إعداد Supabase قبل نشر النسخة للاستخدام الحقيقي.

## المعاينة المحلية

يتطلب المشروع Node.js، ولا يحتاج تثبيت حزم لتشغيل الموقع أو بنائه.

```sh
node serve.cjs
```

افتح `http://127.0.0.1:4173`. عند ترك إعدادات Supabase فارغة تعمل معاينة محلية ببيانات المتصفح فقط، ولا يُرسل بريد. بيانات المعاينة لا تنتقل تلقائيًا إلى Supabase.

## محتويات المشروع

- صفحات HTML وملفات CSS وJavaScript: واجهة الموقع المعتمدة.
- `supabase/`: مخطط قاعدة البيانات، سياسات الصلاحيات، الدالة الخادمية ودليل الربط.
- `vendor/supabase.js`: مكتبة الاتصال اللازمة للموقع.
- `scripts/build.cjs`: إنشاء نسخة النشر والتحقق من إعداداتها.
- `serve.cjs`: تشغيل المعاينة المحلية.
- `verify*.cjs`: اختبارات التطوير والتحقق؛ لا تدخل ضمن نسخة النشر.

حُذفت ملفات التنسيق القديمة غير المستخدمة والنسخة الاحتياطية ونتائج الفحص. يتجاهل Git نواتج البناء والفحص وملفات الأسرار المحلية تلقائيًا.

## التحقق

```sh
node verify-build.cjs
node verify-supabase.cjs
```

اختبارات المتصفح `verify.cjs` و`verify-layout.cjs` و`verify-reports.cjs` و`verify-appearance.cjs` و`verify-site.cjs` تحتاج Playwright وGoogle Chrome وخادم المعاينة. يمكن تحديد مسار Playwright عبر `PLAYWRIGHT_PATH`. بيانات الاختبار معزولة عن جلسة متصفحك.

أُضيف رابط مشروع Supabase والمفتاح العام إلى النسخة الحالية. يجب إكمال إعداد الدالة الخادمية والبريد وعناوين إعادة التوجيه قبل الاستخدام الفعلي. ملف `supabase-config.js` يقبل الرابط والمفتاح العام فقط؛ لا ترفع مفتاح `service_role` أو `sb_secret_` أو أسرار البريد إلى GitHub.
